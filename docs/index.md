# StarLight 文档站

StarLight 是一个运行在 Cloudflare Workers 上的开源社区系统，提供内容发布、社交互动、在线竞赛与社区运营工具。

## 从这里开始

- [了解 StarLight](getting-started/overview.md)：认识项目定位、技术栈和主要功能。
- [本地开发](getting-started/development.md)：安装依赖并启动开发服务器。
- [部署到 Cloudflare](getting-started/deployment.md)：配置 D1 数据库并发布 Worker。
