# 竞赛与 OJ

## 竞赛

`/contest` 用于浏览竞赛列表，进入具体竞赛后查看详情和参与信息。参赛前请阅读竞赛规则、时间限制和提交要求。

## 在线评测

`/oj` 用于浏览题目，题目详情会展示题面和提交入口。提交后可以通过 `/oj/submission/<id>` 查看提交记录和评测结果。

## 题目建议

符合条件的用户可以通过 `/oj/propose` 提交题目建议；审核入口 `/oj/proposals` 面向具有相应权限的管理者。建议内容应包含清晰题面、输入输出说明、样例和数据范围，并确认题目来源合法。

## 排行与记录

- `/leaderboard`：查看排行榜。
- `/achievements`：查看成就。
- `/judgement`：查看评测相关页面。

评测服务的资源限制和判题细节可能随部署环境调整，页面显示结果优先于本文档中的概括说明。
