# 内容与互动

## 发布内容

创建文章前，建议先确定标题、正文结构和引用来源。发布后可以从文章详情页进入编辑页面，修正内容或补充说明。

用户发布的文章、评论、图片和附件原则上归原作者所有；公开发布同时会授予本站为展示、存储和分发内容所需的非独占许可，具体以[用户协议](../about/user-agreement.md)为准。

## 处理通知和私信

通知中心用于查看关注、互动和系统消息。私信适合处理个人交流，不应发送违法内容、垃圾广告或他人的敏感信息。

## 举报与工单

遇到违规内容或账号问题时：

1. 记录内容链接、账号、发生时间和问题描述。
2. 通过站内举报或工单提交信息。
3. 不要重复提交相同事项，也不要公开披露举报中的个人信息。
4. 等待管理员处理；必要时补充截图或复现步骤。

工单页面包括列表、新建、详情和编辑入口。请不要在工单中提交密码、Token 或其他不必要的凭据。
