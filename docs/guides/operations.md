# 团队、工单与管理

## 团队

团队功能入口为 `/team`。用户可以浏览团队、创建团队、查看团队详情，并根据权限管理团队设置和成员申请。

团队管理者应明确成员规则，及时处理加入申请，并对团队公开内容承担相应的管理责任。

## 签到、成就与兑换

签到、成就和积分兑换分别对应 `/checkin` 相关业务、`/achievements` 和 `/redeem` 页面。积分或奖励规则由站点运营配置，用户应以当前页面显示为准，不要尝试绕过限制重复领取。

## 后台管理

管理相关页面包括后台入口、管理员列表、服务器状态和健康检查。它们只应向被授予管理权限的账号开放。管理员操作应遵循最小权限原则，并保留必要的处理记录。

## 安全处理

- 不要把账号密码、Cookie、Token 或 D1 凭据发到工单和公开讨论区。
- 发现漏洞时，向管理员私下报告复现步骤和影响范围。
- 不要对线上站点进行 DDoS、SQL 注入、爆破或其他未经授权的安全测试。
- 生产环境部署前后检查 Worker 日志、D1 访问和管理员权限。
