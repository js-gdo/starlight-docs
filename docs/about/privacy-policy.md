# 隐私政策

生效日期：2026-09-25

## 前言
StarLight社区（下称「本站」）高度重视用户的个人信息保护。
本政策向您说明：我们收集哪些个人信息、如何使用、存储、保护以及您拥有哪些权利。
注册、访问、使用本站服务，即代表您阅读并同意本隐私政策。若不同意，请停止使用本站。

## 1. 我们收集的信息
### 1.1 您主动提交的信息
- 账号信息：用户名、密码（密码将加密存储）、电子邮箱；
- 个人资料：头像、简介、自定义主页信息（**可选填写**，您可以选择不填真实姓名、手机号等敏感信息）；
- 内容信息：您发布的帖子、评论、图片、附件以及您在站内发送的私信；
- 反馈信息：您向管理员提交的工单、投诉、联系信息。

### 1.2 访问时自动收集的信息
当您访问本站，我们可能自动获取：
- 访问日志：IP地址、浏览器类型、设备标识、访问时间、页面浏览记录、页面跳转来源；
- Cookie/本地存储：用于保持登录状态、记住站点偏好、防刷与安全风控。
> 您可以在浏览器设置关闭Cookie，但关闭后部分功能（保持登录）可能失效。

### 1.3 我们**不会主动收集**的信息
在未经您明确许可的前提下，本站**不会**收集身份证号、银行卡、生物识别信息等敏感个人信息。

## 2. 信息使用目的
我们收集信息仅用于以下用途：
1. 账号注册、登录验证、维持账号正常使用；
2. 提供社区基础功能：发帖、评论、私信、内容展示；
3. 安全风控：识别异常登录、垃圾信息、恶意攻击，维护社区安全；
4. 接收您的反馈、投诉，处理侵权举报；
5. 站点统计分析，优化网站体验（统计数据优先做匿名化处理）；
6. 发送必要通知：账号提醒、社区规则变更、系统公告。

> 不会利用您的个人信息做无关营销，未经许可不会推送广告邮件。

## 3. 信息共享与披露
**我们不会向无关第三方出售、出租您的个人信息。**
仅在以下情形才会对外提供信息：
1. 您**主动同意**授权共享；
2. 国家司法机关、行政机关依法出具正式文书要求调取；
3. 为保障本站、其他用户、公共安全，在必要限度内披露（最小必要原则）；
4. 委托服务供应商（如云存储、CDN），服务商仅可按本站要求处理数据，不得另作他用。

## 4. 信息存储与安全
1. 数据存储：您的信息存储于合规服务器；
2. 保存期限：
   - 账号信息：账号存续期间保留；注销账号后，按规则删除或匿名化处理；
   - 访问日志：一般保留不超过90天，到期自动清理；
   - 您发布的公开帖子内容：作为社区内容长期保留（除非您自行删除或管理员按规则删除）；
3. 安全防护：采用加密、访问权限隔离等技术保护数据。
   ⚠️ 互联网无法做到绝对安全，我们尽力防护，但无法保证100%无泄露风险。

## 5. 您的权利
1. **访问权**：可查看自己账号保存的个人资料；
2. **更正权**：在个人设置页修改头像、简介等资料；
3. **删除权**：可自行删除自己发布的帖子/评论；可申请账号注销；
4. **撤回同意**：您可以关闭浏览器Cookie；
5. **投诉权**：如认为我们违规处理个人信息，可联系管理员反馈。

> 账号注销说明：账号注销后，个人资料会清除；但您已经公开发布的内容，可能仍保留在社区（匿名化处理，不再关联您账号）。

## 6. Cookie 说明
本站使用Cookie和本地存储：
- 必要Cookie：维持登录状态、安全校验，无法关闭；
- 非必要Cookie：用于统计、偏好设置，您可浏览器禁用。

## 7. 未成年人保护
如果您是未满14周岁未成年人，请在监护人同意并陪同下使用本站。
如发现未成年人违规提交个人信息，可联系管理员删除相关信息。

## 8. 第三方服务
本站可能引入第三方服务（CDN、代码统计、图片存储等），第三方受其自身隐私政策约束。我们不对第三方的数据处理行为负责。

## 9. 政策更新
本站可随时修订本隐私政策，更新后在网站公示，公示即生效。继续使用本站视为接受新版本。
重大变更时，我们会在社区发布公告提示。
