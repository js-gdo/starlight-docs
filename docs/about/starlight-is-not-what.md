# StarLight不是什么
## StarLight不是发表涉政、黄赌毒等内容的地方
    根据中华人民共和国法律的相关规定，StarLight不允许发布违法违规内容。
    如果有违规发布的情况，我们将采取措施，并可能上报有关部门。
## StarLight不是靶场
    StarLight是一个社区软件，不是一个靶场。
    任何组织和个人不得私自对StarLight进行包括但不限于DDoS、SQL注入等操作。
## StarLight不是私人恩怨的处理地
    如果您与其他用户有私人恩怨，请私下解决，不要在本社区处理。
## StarLight不是AI训练中心
    任何组织和个人不得使用StarLight进行AI训练。
